# React Router Checkpoint — GOMYCODE

Suite de l'application de films (React Hooks Checkpoint) avec **react-router-dom**.

- Chaque film a maintenant une `description` et un lien de **bande-annonce** (`trailer`, vidéo intégrée).
- Cliquer sur une carte (`Link` vers `/movie/:id`) ouvre la page **description + bande-annonce** (`MovieDetails`, `useParams`).
- Sur cette page, un bouton permet de **revenir à l'accueil**.
- La page d'accueil garde le filtre (titre / note) et l'ajout de films.

```bash
npm install
npm start
```
